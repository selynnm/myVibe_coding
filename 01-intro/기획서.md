# 자기소개 웹페이지 기획서

## 1. 프로젝트 개요

수업에서 처음 만난 친구들이 모카의 취미를 살펴볼 수 있도록 한 페이지짜리 미니홈을 만든다.

## 2. 가상 인물 설정

- **별명** — 모카
- **학년** — 대학교 2학년
- **전공** — 미디어콘텐츠학과
- **성격** — 처음에는 조금 조용하지만, 좋아하는 이야기가 나오면 말이 많아진다.
- **취미** — 산책하며 풍경 사진 찍기, 카페에서 과제하기, 친구와 보드게임 하기
- **관심 분야** — 풍경 사진과 짧은 영상 만들기. 요즘은 학교 근처에서 노을이 잘 보이는 곳을 찾고 있다.
- **이번 학기 목표** — 수업에서 만난 친구들과 각자 좋아하는 캠퍼스 장소를 모아 짧은 영상으로 소개한다.
- **인사말** — 안녕하세요, 모카예요! 수업에서 만나 반가워요. 여러분은 캠퍼스에서 어디를 가장 좋아하나요?

## 3. 화면 구성

### 3.1 첫인사

‘모카의 겨울방’ 제목과 인사말을 표시한다.

### 3.2 프로필

별명, 학년, 전공, 성격, 관심 분야와 이번 학기 목표를 카드에 표시한다.

### 3.3 겨울 미니룸

벽에 노을 풍경 그림을 걸고, 카메라·노트북·커피를 책상에 놓는다. 옆 탁자는 보드게임판과 주사위, 게임 말로 꾸민다. 방 아래에는 취미 세 가지를 글로 표시한다. 모카는 가구 앞을 걷고, 카메라와 보드게임 소품이 움직인다. 버튼으로 움직임을 멈추거나 다시 재생한다.

## 4. 디자인 방향

- 전체 배경은 짙은 남색으로 고정한다.
- 첨부 이미지에서 하늘색, 연두색, 둥근 창 테두리를 참고하고, 창 제목줄 아래에 모카의 겨울 방을 배치한다.
- 금빛 전구, 눈 내리는 창문, 나무색 가구와 러그로 겨울 분위기를 만든다.
- 설치된 노토 산스 계열을 우선 사용하고, 없으면 맑은 고딕 등 비슷한 한글 산세리프 글꼴로 표시한다.
- 좁은 화면에서는 방 전체의 비율을 유지하면서 줄이고, 프로필 카드와 취미 목록은 한 줄에 하나씩 표시한다.

## 5. 사용할 기술

HTML로 소개와 취미 목록을 구성하고, CSS와 이모지로 방과 소품을 표현한다. CSS로 배경색과 움직임을 지정하고 JavaScript로 재생과 멈춤을 제어한다. 기기에서 움직임 줄이기를 선택했다면 멈춘 상태로 시작한다.

## 6. 파일 구성

- `기획서.md` — 화면 구성과 완료 기준
- `index.html` — 소개 내용과 디자인을 담은 단일 웹페이지 파일

## 7. 구현 단계

1. 제목, 인사말, 프로필과 취미 목록을 정리한다.
2. 남색 배경에 겨울 미니룸을 만들고 취미를 표현하는 소품을 배치한다.
3. 모카와 소품을 움직이게 하고 재생과 멈춤 버튼을 연결한다.
4. 컴퓨터와 좁은 화면에서 방과 글이 잘리지 않는지 확인한다.

## 8. 완료 기준

- [ ] `index.html`을 더블클릭하면 인터넷 연결 없이 브라우저에서 열린다.
- [ ] 배경은 남색으로 고정되고 배경색 변경 버튼이 없다.
- [ ] 별명, 학년, 전공, 성격, 취미 세 가지, 관심 분야, 목표와 인사말이 표시되며 각 취미를 보여 주는 소품이 방에 있다.
- [ ] 금빛 전구와 눈 내리는 창문이 보이고 좁은 화면에서 가로로 밀지 않아도 내용을 읽을 수 있다.
- [ ] 노토 산스 계열을 우선 사용하고 없으면 준비된 한글 글꼴로 표시한다.

- [ ] 모카가 방향을 바꾸면서 방 안을 걷고, 소품이 움직인다.
- [ ] 버튼으로 움직임을 멈추고 다시 재생할 수 있다.

## 9. 제외 범위 및 주의사항

외부 라이브러리, 외부 서비스, 서버, 데이터베이스를 사용하지 않는다. 실명, 학번, 이메일, 전화번호와 실제 사진을 넣지 않는다. 화면 문구와 코드 주석은 한국어로 작성한다.
